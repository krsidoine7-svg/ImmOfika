# Directives de Typographie Markdown (Inspirées de nanoGPT)

Pour que les données soient optimales pour l'entraînement d'un LLM ou la génération de quiz :
1. Pas de sauts de ligne multiples inutiles (maximum 1 ligne vide entre deux paragraphes).
2. Utilisez des titres stricts (`#`, `##`, `###`) pour délimiter les sections sémantiques.
3. Les tableaux doivent être correctement formatés en Markdown standard.
4. Aucun code HTML ou balise XML parasite ne doit subsister, exception faite des tags explicites : `[IMPORTANT: Concept Clé]`, `[EXEMPLE]`, `[SCÉNARIO]`.
