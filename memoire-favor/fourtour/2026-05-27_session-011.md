# Session du 27 Mai 2026 (Session-011) — Résolution du plantage 400 sur la création/édition des biens (Server Actions Body Limit & CSRF)

## 🎯 Objectifs de la session
- Diagnostiquer et corriger le crash 400 (Bad Request) rencontré sur le serveur lors de la création d'un bien immobilier (`/admin/biens/nouveau`) ou de sa modification, en particulier sur l'environnement de production.

## 🔍 Diagnostic & Analyse d'Impact
1. **Erreur observée** :
   - Sur l'URL publique `https://favor-ci.vercel.app/admin/biens/nouveau`, la soumission du formulaire renvoyait l'erreur suivante :
     - `nouveau:1 Failed to load resource: the server responded with a status of 400 ()`
     - `Next.js Client Error Boundary: Error: An unexpected response was received from the server.`
2. **Explication technique** :
   - Par défaut, Next.js restreint la taille du corps des requêtes (body size limit) pour les Server Actions à **1 Mo** pour des raisons de sécurité.
   - Les photos de biens immobiliers capturées par les utilisateurs font généralement entre 1.5 Mo et 5 Mo (limite maximale autorisée par le client : 5 Mo).
   - Lorsque l'utilisateur téléchargeait une photo supérieure à 1 Mo, Next.js interceptait la requête et renvoyait un code HTTP **400 Bad Request** avant même que l'Action Serveur `createBienAction` ne soit appelée.
   - De plus, les règles de comparaison d'origines de Next.js pour les Server Actions en production peuvent renvoyer un code 400 si l'en-tête `Origin` ne correspond pas exactement au domaine principal.

## 🛠️ Réalisations & Corrections
1. **Configuration du Body Size Limit & Allowed Origins (`next.config.ts`)** :
   - Modification de [next.config.ts](../../next.config.ts) pour y injecter la clé `experimental.serverActions` :
     - Augmentation de `bodySizeLimit` à **10 Mo** (`10mb`) pour accepter sereinement de grandes images haute résolution sans plantage.
     - Configuration de `allowedOrigins` avec `['favor-ci.vercel.app', 'localhost:3000']` afin de lever tout faux-positif de validation d'origine CORS sur l'environnement Vercel et en local.

## 📝 Décisions techniques
- Porter la limite de taille des requêtes Server Actions à 10 Mo pour s'aligner avec les besoins d'upload média (photos haute qualité).
- Sécuriser l'origine des requêtes en listant explicitement le domaine de production `favor-ci.vercel.app` dans les allowed origins de Next.js.
