# Addendum — Désactivation Génération Automatique Contrat Code & Aperçu In-App (26 Juillet 2026)

## 📌 Modifications Conformes aux Instructions Vocales Utilisateur
1. **Reçus Seuls Auto-Générés** : Le système génère uniquement les **Reçus d'Acompte (`RecuPDF`)**. La génération automatique de contrats par le code est désactivée ; les contrats sont exclusivement révisés et téléversés en PDF par l'agent.
2. **Aperçu PDF Directement Dans l'Application (In-App Modal)** :
   - Le clic sur **`[👁️ Aperçu PDF du Contrat]`** n'ouvre plus d'onglet externe ou de lien blob indépendant, mais ouvre une **modale d'aperçu In-App (`<Dialog>`)** directement dans l'application.
3. **Panneau d'Emplacements des 3 Champs de Signature** :
   - Affichage interactif dans la modale d'aperçu In-App des 3 champs activés : (1) Mention *"Lu et approuvé"*, (2) Date du jour horodatée, (3) Cadre de signature.
