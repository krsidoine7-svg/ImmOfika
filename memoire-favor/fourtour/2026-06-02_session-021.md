## 🎯 Objectif
- Résoudre l'avertissement de console lié à Framer Motion : `[browser] Please ensure that the container has a non-static position, like 'relative', 'fixed', or 'absolute' to ensure scroll offset is calculated correctly. (<anonymous>)` sur la page d'accueil `/`.

## 🛠️ Actions Réalisées
- **Analyse du Warning** :
  - Identification des utilisations de `useScroll` dans le projet : `HeroSection.tsx` et `BiensSection.tsx`.
  - Constat : `BiensSection.tsx` contient un composant `<section id="biens" className="py-32 bg-white dark:bg-secondary/30 overflow-hidden">` qui était `static` par défaut. Comme il possède la propriété `overflow-hidden`, Framer Motion le détecte comme un conteneur de défilement potentiel pour le hook `useScroll` dans `PropertyCard`. Étant `static`, cela déclenche l'avertissement de console.
  - Constat global : La page d'accueil et les layouts n'avaient pas de positionnement `relative` explicitement défini sur `html` et `body`, ce qui peut perturber les calculs d'offset de Framer Motion lorsque le conteneur par défaut est la fenêtre du navigateur.

- **Résolution Technique** :
  - **Modification de [BiensSection.tsx](file:///c:/Users/Toto.ADMINISTRATOR/FavorCI/src/components/public/BiensSection.tsx)** : Ajout de la classe `relative` à l'élément de section : `<section id="biens" className="relative py-32 bg-white dark:bg-secondary/30 overflow-hidden">`.
  - **Modification de [layout.tsx](file:///c:/Users/Toto.ADMINISTRATOR/FavorCI/src/app/layout.tsx)** : Ajout des classes `relative` sur les éléments `html` et `body` :
    - `html` : `relative h-full antialiased font-sans ...`
    - `body` : `relative min-h-full flex flex-col`
  - **Modification de [globals.css](file:///c:/Users/Toto.ADMINISTRATOR/FavorCI/src/app/globals.css)** : Standardisation dans `@layer base` pour que `body` et `html` héritent de la propriété `relative` :
    ```css
    body {
      @apply bg-background text-foreground relative;
    }
    html {
      @apply font-sans relative;
    }
    ```

- **Validation** :
  - Lancement de la vérification de type TypeScript (`npx tsc --noEmit`) pour s'assurer qu'aucune régression n'a été introduite.
