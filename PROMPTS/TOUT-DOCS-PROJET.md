## 14. Commandes de Développement — Cheat Sheet

```bash
# Installation
npm install
cp .env.example .env.local

# Développement
npm run dev               # Serveur dev http://localhost:3000
npm run build             # Build production
npm run start             # Serveur production local
npm run lint              # ESLint
npm run type-check        # TypeScript check

# Base de données
npm run db:generate       # Générer migrations Drizzle
npm run db:migrate        # Appliquer migrations
npm run db:studio         # Interface Drizzle Studio
npm run db:seed           # Insérer données de référence

# Tests
npm run test              # Tests unitaires (Vitest)
npm run test:watch        # Tests en mode watch
npm run test:e2e          # Tests E2E (Playwright)
npm run test:coverage     # Couverture des tests

# Git
git checkout -b feature/F_XX-nom   # Nouvelle branche
git add . && git commit -m "feat(scope): description"
git push origin feature/F_XX-nom

# Analyse
npm run analyze           # Analyse du bundle
```
