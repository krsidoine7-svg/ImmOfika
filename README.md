# Anyilo — Plateforme Immobilière & Promotion Agréée

> **Note 2026-11-22** : le paiement en ligne a été entièrement retiré d'Anyilo (aucune passerelle ni agrégateur). Les passages qui le décrivent sont historiques. Revenus : facturation des annonceurs au nombre de clients obtenus (voir `docs/PLAN-CORRECTIONS-AUDIT.md`).


Anyilo est une plateforme SaaS immobilière épurée, modulaire et 100% réplicable pour les agences immobilières, les propriétaires, les gestionnaires de biens et les promoteurs agréés.

## Charte Visuelle Officielle
- **Palette** : Vert Émeraude Menthe (`#10B981`, `#059669`, `bg-emerald-50`, `text-emerald-700`) & Blanc Pur (`#FFFFFF`).
- **Design** : Minimaliste, lumineux, moderne et axé sur la clarté et la conversion.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Supabase / Drizzle ORM
- passerelle de paiement (retirée) Payment Gateway
