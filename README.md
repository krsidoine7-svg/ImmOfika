# ImmOfika — Plateforme Immobilière & Promotion Agréée

ImmOfika est une plateforme SaaS immobilière épurée, modulaire et 100% réplicable pour les agences immobilières, les propriétaires, les gestionnaires de biens et les promoteurs agréés.

## Charte Visuelle Officielle
- **Palette** : Vert Émeraude Menthe (`#10B981`, `#059669`, `bg-emerald-50`, `text-emerald-700`) & Blanc Pur (`#FFFFFF`).
- **Design** : Minimaliste, lumineux, moderne et axé sur la clarté et la conversion.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Supabase / Drizzle ORM
- Paystack Payment Gateway
